  # library-management-system-group-6
A web-based Library Management System built with PHP and MySQL on XAMPP. Librarians log in securely to add, edit, search and delete books and members, and issue and return loans, with enforced borrowing rules, transactions and prepared statements. Built for Database II CAT 2.
## Key Features
- Secure librarian authentication
- Add, edit, search, and delete books and members
- Book loan issuance and return tracking with enforced rules

## Technologies Used
- PHP & MySQL (XAMPP)
- HTML, CSS, JavaScript
